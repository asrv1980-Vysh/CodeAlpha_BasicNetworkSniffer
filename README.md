CodeAlpha Basic Network Sniffer

Project Overview

A basic network sniffer developed using Python and Scapy as part of the CodeAlpha Cyber Security Internship.

Features

- Captures network packets
- Displays source IP address
- Displays destination IP address
- Identifies common protocols such as TCP, UDP and ICMP
- Displays captured packet information in the terminal

Technologies Used

- Python
- Scapy

How to Run

1. Install Python.
2. Install Scapy using:
   "python -m pip install scapy"
3. Run the "main.py" file.
4. The program captures a limited number of packets and displays their information.

Project Output

The program displays:

- Source IP
- Destination IP
- Protocol
